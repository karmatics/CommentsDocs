2. Executive Summary & The Grand Strategic Opportunity

For more than 40 years, the commercial CAD industry has trapped users inside the paradigm created in the 1980s by Autodesk AutoCAD: command-line prompt loops, manual coordinate entry (such as typing @10.5,0,0), cumbersome User Coordinate System (UCS) plane rotation, and proprietary file lock-in.

In 1995, Rob Brown introduced AccuDraw and SmartLine in MicroStation 95, proving that computer-aided drafting could operate at 2x to 4x the speed by replacing command prompts with a kinetic, floating, context-aware 3D coordinate compass under the user's cursor.

The Catalyst: ArtCraft's CADCraft Project

Brandon Thomas and the ArtCraft team recently released CADCraft—a clean-room, pure-Rust implementation of AutoCAD that runs natively on desktop operating systems and compiles to WebAssembly for the browser. CADCraft is fast, open-source, and supports DXF/DWG entities, layers, and AI agents via Model Context Protocol (MCP).

However, CADCraft currently inherits AutoCAD's historic limitations: it is strictly 2D planar drafting, lacks real 3D construction plane rotation, has no floating kinetic compass, and relies on traditional AutoCAD typing.

Our Move: We are stepping in at the ground floor. We are creating CommentsDocs to tack the complete 3D AccuDraw constraint engine, SmartLine chaining, and a wireless mobile P2P Touch Controller onto CADCraft in the most flexible, modular way possible—giving AutoCAD and MicroStation users the most fluid, open CAD platform ever built.

3. The Five Core Architectural Pillars of CommentsDocs

Pillar I: Complete Modularity (The "Tack-On" Philosophy)

CommentsDocs must not be a brittle, monolithic rewrite. It is designed as an independent, modular subsystem that can be bolted onto CADCraft or any other open-source CAD project:

  • Input Interception Hook: Rather than replacing CADCraft's internal Rust geometry engine, AccuDraw intercepts raw cursor motion and keystrokes, calculates exact geometric constraints in 3D, and feeds resolved snap coordinates directly into the command pipeline.
  • Permanent Agentic Fork Workflow: Whenever CADCraft releases an upstream update, an automated software agent pulls the release, verifies our Wasm/AST interception points, re-applies our AccuDraw modules, and verifies tests without human merge friction.
  • Pluggable Exporters: If a user wants to output to a new format, they can simply plug in a lightweight translation module (SVG, glTF, STEP, custom JSON, or DXF).

Pillar II: Zero-Cost Open Web Access & Token-Free LLM Paste Driving

We want users around the world to access and drive this CAD platform directly over the web on our website without installation barriers, credit cards, or expensive API keys:

  • Runs 100% in Browser: Powered by WebGL (Three.js) and Rust compiled to WebAssembly.
  • Token-Free LLM Driving via Paste: Users can open any web AI interface (Claude, Gemini, ChatGPT, DeepSeek), converse with the model for free, and copy structured HTML container code blocks: 
    <script data-file="CommentsDocs/src/CustomPart.js" data-method="CustomPart.draw" data-action="patch">
  // Generated drawing or surgical tool patch...
</script>
    Tapping "Paste from Chatbot" evaluates and compiles the drawing live in browser memory—giving users full AI-driven CAD automation on a token-by-token basis without running up API bills.
  • MCP Agent Automation: For automated background workflows, the engine exposes Anthropic Model Context Protocol (MCP) tool endpoints so autonomous agents can drive AccuDraw directly.

Pillar III: The Wireless P2P Touch Controller

One of the crowning advantages of this platform is our mobile P2P touch control system (implemented in TouchController). It turns any smartphone or tablet into a dedicated, low-latency WebRTC dual-surface controller:

  • Left Trackpad (3D View Navigation):
    • 1 Finger: 3D orbit and rotation with physics-based inertia. Double-tap toggles between Rotate and Pan.
    • 2 Fingers: Pinch-to-zoom.
    • 3 Fingers: Perspective camera FOV adjustment.
    • 4 Fingers: Direct, kinetic AccuDraw Z-elevation adjustment with sliding momentum.
  • Right Trackpad (Controls & Tool Encoders):
    • Vertical Swipe: Glides through active tool settings and compass sliders with smooth hover tracking.
    • Horizontal Swipe: Continuously dials in selected slider and dimension parameters.
    • Single Tap: Toggles boolean tool states (e.g., "Make Copy", "Arbitrary Pivot") or opens direct numeric input.

This tactile dual-surface control integrates with the screen in a way desktop AutoCAD never could, providing an unmatched drafting experience.

Pillar IV: AccuDraw 3D & SmartLine (Proven MicroStation Power)

We are bringing the proven mathematics from accuCad into this ecosystem:

  • Floating Context-Aware Compass: Renders as an adaptive squircle (curved square transitioning to a circle in polar mode) that aligns with drawing planes in 3D space.
  • Single-Key Plane Alignment (SmartDrawKeys):
    • T: Orient compass to Top plane.
    • F: Orient compass to Front plane.
    • S: Orient compass to Side plane.
    • V: Orient compass to current View rotation.
    • Space: Instantly toggle between Rectangular (X, Y, Z) and Polar (Distance, Angle).
    • X, Y, Z: Lock specific axes.
    • L: Smart Lock (locks the axis closest to the cursor trajectory).
    • Enter: Confirm and lock current numeric input.
    • Esc: Multi-tier escape (clears active buffer → unlocks active field → unlocks all axes → resets tool).
  • SmartLine Chaining: Draw continuous segments where tangent arcs, sharp corners, and filleted transitions blend dynamically without breaking the drawing flow.

Pillar V: Anti-Lock-In Geometry Hub & Non-Destructive Reference Slicing

Commercial CAD vendors weaponize file formats to force perpetual upgrades. CommentsDocs takes inspiration from MicroStation's historic reference file architecture to eliminate lock-in:

  • Selective Geometric Slicing: Users can open an AutoCAD DWG or DXF file, extract only a specific sub-assembly, layer, or spatial bounding box, and work on it independently.
  • External Metadata Layering: Add rich metadata, parametric constraints, and AccuDraw construction data stored cleanly alongside the model without mutating the base file structure.
  • Non-Destructive Round-Tripping: Save modified components back into the original DWG/DXF file without corrupting proprietary blocks or overriding unaffected entities.
  • Open Export Freedom: Export partial or full models to open formats (glTF, STEP, SVG, JSON) on demand.
